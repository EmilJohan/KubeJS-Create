# KubeJS-Create

This is a fork of [KubeJS Create](https://github.com/KubeJS-Mods/KubeJS-Create/) with support for Minecraft 1.21.1 and NeoForge. Supports Create 6.

## Status

Currently, I've only tested the processing recipes which seem to work. There are still errors when using various Create addons but they are not fatal.

Custom Sequenced Assembly recipes are disabled until a `NestedRecipeComponent` codec is implemented in KubeJS.
